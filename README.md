# chrasriz.com

Personal portfolio of Rasikh Rizwan — Cybersecurity Analyst & IT Professional.

Fully static site built with Next.js (App Router), React, TypeScript, Tailwind CSS, and framer-motion. Fonts are self-hosted (Geist variable fonts in `src/fonts/`). No backend, API routes, or data store.

## Development

```bash
npm install
npm run dev     # http://localhost:3000
```

## Checks

```bash
node_modules/.bin/tsc --noEmit
node_modules/.bin/next build
node_modules/.bin/eslint .
```

See `CLAUDE.md` for the engineering rules this repo follows.
